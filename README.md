# 🤖 Big Data Analytics Chatbot

An AI-powered chatbot built using Python, Groq API, and the GPT-OSS-20B model to answer questions and simplify Big Data Analytics concepts.

## 📌 About the Project

The Big Data Analytics Chatbot is a simple AI application that generates informative answers to user questions using a large language model. It integrates the Groq API with Python to provide fast responses and easy-to-understand explanations.

This project is designed to help students and beginners understand Big Data Analytics concepts more easily.

## ✨ Features

- 🤖 AI-powered question answering
- ⚡ Fast responses using the Groq API
- 📚 Simple explanations of Big Data Analytics concepts
- 🐍 Easy-to-understand Python implementation
- 🔐 Secure API key management using environment variables
- 🎓 Helpful for students and beginners

## 🛠️ Technologies Used

- **Programming Language:** Python
- **AI API:** Groq API
- **Language Model:** GPT-OSS-20B
- **Development Platform:** Google Colab
- **Library:** Groq Python SDK

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/BigData-Analytics-Chatbot.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project Folder

```bash
cd BigData-Analytics-Chatbot
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the API Key

Get an API key from [Groq Console](https://console.groq.com/).

Set the `GROQ_API_KEY` environment variable.

**Windows PowerShell:**

```powershell
$env:GROQ_API_KEY="your_api_key_here"
```

Do not upload your actual API key to GitHub.

### 5. Run the Application

```bash
python app.py
```
